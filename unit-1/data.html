CONCEPT 01

What is Data?

Simple Definition

Data means raw facts, values or information that can be processed by a computer.

These values may represent numbers, characters, text, images, audio, video, measurements or any other form of information.

In Data Structures, our main goal is to understand how this data can be stored, organized and accessed efficiently.

DATA CLASSIFICATION

Types of Data

Data can be classified in different ways. For DSA, understanding primitive and non-primitive data is especially important.

🔢

Primitive Data

Basic data types provided by a programming language. Examples: int, char, float, double and bool.

🧩

Non-Primitive Data

More complex structures created using primitive data types. Examples: arrays, structures, linked lists, stacks, queues and trees.

DATA IN C++

How does a computer store data?

In C++, variables are used to store data. The data type tells the compiler what kind of value is being stored.
