CONCEPT 01

What is Array Deletion?

Simple Definition

Deletion is the operation of removing an existing element from an array at a particular position.

Suppose our array is:

If we delete 20 from index 1, the elements after it need to shift toward the left.

CORE IDEA

Delete = Remove + Shift

The most important thing to remember is: after deleting an element from the middle, the elements on its right move one position to the left.

THREE CASES

Types of Deletion

⬅️

Beginning

Delete the element at index 0. Almost every remaining element has to shift one position left.

position = 0 → O(n)
🎯

Middle / Any Position

Delete the selected element and shift all elements after it toward the left.

0 ≤ position < n
➡️

End

Delete the last logical element. No shifting of other elements is required.

position = n - 1 → O(1)

ALGORITHM

Deletion at Given Position

Algorithm

Start
→
Validate Position
→
Shift Left
→
Decrease Size
→
Stop

Step 1: Check whether the position is valid.

Step 2: Start from the deletion position.

Step 3: Copy the next element into the current position.

Step 4: Continue shifting until the last element.

Step 5: Decrease the logical size by 1.

C++ IMPLEMENTATION

Delete Element at Given Position

deletion.cpp 
#include <iostream>

using namespace std;

int main()
{
    int arr[10] =
        {10, 20,
         30, 40,
         50};

    int n = 5;

    int pos = 2;

    if(
        pos < 0 ||
        pos >= n
    )
    {
        cout <<
        "Invalid position";

        return 0;
    }

    for(
        int i = pos;
        i < n - 1;
        i++
    )
    {
        arr[i] = arr[i + 1];
    }

    n--;

    for(
        int i = 0;
        i < n;
        i++
    )
    {
        cout << arr[i] << " ";
    }

    return 0;
}

Important Lines

The important statement is: arr[i] = arr[i + 1]

This copies the next element into the current position, effectively removing the selected element.

The loop starts from the deletion position and moves toward the end.

Finally, n-- reduces the logical size of the array.

COMPLEXITY

Time Complexity of Deletion

O(1) Best Case — Delete at End
O(n) Worst Case — Delete at Beginning
O(n) Average Case
Position Shifting Time Reason
Beginning Almost n elements O(n) All remaining elements shift left
Middle Some elements O(n) Elements after position shift
End No shifting O(1) Only size decreases

AKTU Exam Point: Array deletion from an arbitrary position can require shifting of elements, therefore its worst-case time complexity is O(n) .
