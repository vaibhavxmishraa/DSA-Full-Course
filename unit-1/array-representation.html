CONCEPT 01

How is an Array Represented?

The Basic Idea

An array is represented in memory using contiguous memory locations.

Suppose we have:

int arr[5] = {10, 20, 30, 40, 50};

If one integer occupies 4 bytes and the starting address is 1000, then the elements will occupy consecutive memory locations.

1000 → 1004 → 1008 → 1012 → 1016

IMPORTANT FOR AKTU

Row-Major Order

What is Row-Major Order?

In row-major order, elements are stored row by row.

For this matrix:

10 20 30 40
50 60 70 80

Row-major memory sequence becomes:

10 → 20 → 30 → 40 → 50 → 60 → 70 → 80

Address(A[i][j]) = Base + ((i × Columns) + j) × Size For zero-based indexing

Example

Suppose:
Base = 1000
Columns = 4
Size = 4 bytes
Find address of A[1][2].

1000 + ((1×4)+2)×4

= 1024

Remember

In row-major representation, the last dimension changes fastest.

ROW → ROW → ROW
IMPORTANT CONCEPT

Column-Major Order

What is Column-Major Order?

In column-major order, elements are stored column by column.

For this matrix:

10 20 30
40 50 60
70 80 90

Column-major sequence becomes:

10 → 40 → 70 → 20 → 50 → 80 → 30 → 60 → 90

Address(A[i][j]) = Base + ((j × Rows) + i) × Size Zero-based indexing
COMPARISON

Row-Major vs Column-Major

🟣 Row-Major

Elements are stored row by row.

Example:
Row 1 → Row 2 → Row 3

Commonly associated with languages such as C and C++.

ROW-WISE STORAGE

🔵 Column-Major

Elements are stored column by column.

Example:
Column 1 → Column 2 → Column 3

Commonly associated with languages such as Fortran.

COLUMN-WISE STORAGE
C++ IMPLEMENTATION

2D Array in C++

matrix.cpp 
#include <iostream>

using namespace std;

int main()
{
    int matrix[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    for(int i = 0; i < 2; i++)
    {
        for(int j = 0; j < 3; j++)
        {
            cout << matrix[i][j] << " ";
        }

        cout << endl;
    }

    return 0;
}

Output

10 20 30
40 50 60

Outer loop controls the rows.

Inner loop controls the columns.

Therefore, the traversal happens row by row.

WHY ARRAYS?

Advantages of Array Representation

⚡

Fast Random Access

Any element can be directly accessed using its index in O(1) time.

🧠

Cache Friendly

Contiguous memory often gives arrays good cache locality and efficient sequential traversal.

📦

Simple Structure

Arrays are easy to understand and form the foundation of many advanced structures.

🔗

Foundation of DSA

Strings, matrices, heaps and many algorithms are closely related to arrays.
