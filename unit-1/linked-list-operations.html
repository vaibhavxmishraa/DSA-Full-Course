Algorithm

1️⃣ Start with temp = head.
2️⃣ Jab tak temp != NULL ho, data print karo.
3️⃣ temp = temp → next.
4️⃣ NULL aane par stop. 

void display(Node* head)
{
    Node* temp = head;

    while(temp != NULL)
    {
        cout << temp->data << " ";

        temp = temp->next;
    }
}

Insertion at Beginning — C++ 


void insertBeginning(Node*& head, int value)
{
    Node* newNode = new Node();

    newNode->data = value;

    newNode->next = head;

    head = newNode;
}
⏱️ Time Complexity: O(1)

06. Searching

Linked List mein generally linear search use hoti hai. Head se start karke har node ka data target se compare karte hain.

10
→
20
→
30 🎯 

bool search(Node* head, int key)
{
    Node* temp = head;

    while(temp != NULL)
    {
        if(temp->data == key)
            return true;

        temp = temp->next;
    }

    return false;
}
⏱️ Worst Case Time Complexity: O(n)
