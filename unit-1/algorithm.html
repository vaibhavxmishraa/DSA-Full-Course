CONCEPT 01

What is an Algorithm?

Simple Definition

An algorithm is a finite set of well-defined instructions that are followed in a specific order to solve a problem.

Simple language mein: Kisi problem ko solve karne ke step-by-step instructions ko Algorithm kehte hain.

Example: Tea banane ke liye bhi ek sequence follow karte ho — water boil karo, tea leaves add karo, milk add karo, sugar add karo, etc.

MUST REMEMBER

Characteristics of an Algorithm

📥

Input

Algorithm can have zero or more inputs.

📤

Output

It must produce at least one result.

🎯

Definiteness

Every step should be clear and unambiguous.

⏳

Finiteness

Algorithm must terminate after finite steps.

⚙️

Effectiveness

Each step must be practically executable.

HOW IT WORKS

Anatomy of an Algorithm

01

Understand the Problem

First clearly understand what problem needs to be solved.

02

Identify Input

Determine what data will be given to the algorithm.

03

Define Processing

Decide which operations must be performed on the input.

04

Produce Output

The algorithm should generate the required result.

05

Analyze Efficiency

Check how much time and memory the algorithm requires.

PSEUDOCODE

Write an Algorithm Before Code

Pseudocode is a simple, human-readable way of describing an algorithm before converting it into an actual programming language.

even-odd.pseudo 
START

INPUT N

IF N % 2 == 0 THEN

    PRINT "Even"

ELSE

    PRINT "Odd"

END IF

STOP
FROM ALGORITHM TO CODE

Same Algorithm in C++

main.cpp 
#include <iostream>

using namespace std;

int main()
{
    int n;

    cout << "Enter a number: ";
    cin >> n;

    if(n % 2 == 0)
    {
        cout << "Even";
    }
    else
    {
        cout << "Odd";
    }

    return 0;
}

IMPORTANT DIFFERENCE

Algorithm vs Program

Algorithm Program
Step-by-step solution to a problem. Actual implementation of that solution.
Language independent. Written in a programming language.
Easy to understand conceptually. Executed by a computer.
Can be represented using pseudocode. Written using syntax of a language.
NEXT CONCEPT

Good Algorithm = Efficient Algorithm

Sirf correct answer dena enough nahi hai. Hume ye bhi dekhna hota hai ki algorithm kitna fast hai aur kitni memory use karta hai.

Isi liye hum algorithms ko analyze karte hain using:

Time Complexity → Algorithm ko execute hone mein kitna time lagta hai.

Space Complexity → Algorithm ko kitni extra memory chahiye.
