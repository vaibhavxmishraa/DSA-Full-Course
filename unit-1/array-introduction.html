CONCEPT 01

What is an Array?

Simple Definition

An array is a linear data structure that stores a fixed number of elements of the same data type in contiguous memory locations.

Example:

int marks[5] = {85, 72, 91, 67, 88};

Here:

marks → array name

5 → number of elements

int → data type

Each element can be accessed using its index.

CORE PROPERTIES

Characteristics of Arrays

🧩

Same Data Type

Normally, elements of an array have the same data type. Example: int array stores integers.

🧠

Contiguous Memory

Array elements are stored next to each other in memory.

⚡

Fast Access

Using an index, an element can be directly accessed in O(1) time.

MOST IMPORTANT

Array Indexing

C++ arrays use zero-based indexing.

That means the first element is stored at index 0, not 1.

arr[0] → First Element
arr[1] → Second Element
arr[n-1] → Last Element

MEMORY CONCEPT

Address Calculation in Array

Why is Array Access O(1)?

Because the address of any element can be calculated directly using its index.

Suppose:

Base address = 1000
Size of int = 4 bytes
Required index = 3

Address = Base + (Index × Size)

Example

Address of arr[3]:

1000 + (3 × 4)

= 1012
arr[3] is located at memory address 1012.
C++ IMPLEMENTATION

Declaring an Array

array.cpp 
#include <iostream>

using namespace std;

int main()
{
    int marks[5];

    marks[0] = 85;
    marks[1] = 72;
    marks[2] = 91;
    marks[3] = 67;
    marks[4] = 88;

    cout << marks[2];

    return 0;
}

What happened?

We created an integer array containing 5 positions.

Then values were inserted using indexes from 0 to 4.

Finally:

marks[2] = 91

Direct access makes array retrieval extremely fast.

SYNTAX

Array Initialization

Method 1 — Declaration only

int arr[5];

Method 2 — Declaration + Initialization

int arr[5] = {10,20,30,40,50};

Method 3 — Size automatically determined

int arr[] = {10,20,30,40,50};

COMPLEXITY

Array Operation Complexity

Basic Array Operations

Access: O(1)

Search: O(n)
(Linear Search)

Insertion: O(n)

Deletion: O(n)
