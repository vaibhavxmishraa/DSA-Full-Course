CONCEPT 01

What is Searching?

Simple Definition

Searching is the process of finding a particular element, called the key / target , in a data structure.

For example, if we have:

10
25
35
42
60

And our target is 42 , searching tells us that it exists at index 3 .

CORE CONCEPT

Two Major Searching Techniques

🔍

Linear Search

Checks every element one by one from beginning to end until the target is found.

Best: O(1) • Worst: O(n)
Works on sorted + unsorted arrays
⚡

Binary Search

Repeatedly divides a sorted array into two halves and eliminates the impossible half.

Best: O(1) • Worst: O(log n)
Array must be sorted

ALGORITHM

Linear Search Algorithm

Step 1: Start from index 0.

Step 2: Compare current element with the target.

Step 3: If equal, return the index.

Step 4: Otherwise move to the next element.

Step 5: If array ends, return -1.

C++ IMPLEMENTATION

Linear Search in C++

linear-search.cpp 
#include <iostream>

using namespace std;

int main()
{
    int arr[] =
        {10, 25,
         35, 42,
         60};

    int n = 5;

    int target = 42;

    int position = -1;

    for(
        int i = 0;
        i < n;
        i++
    )
    {
        if(
            arr[i] == target
        )
        {
            position = i;
            break;
        }
    }

    if(
        position != -1
    )
    {
        cout <<
        "Found at index: "
        << position;
    }
    else
    {
        cout <<
        "Element not found";
    }

    return 0;
}

Code Logic

The loop starts at index 0 and checks every element.

When arr[i] == target becomes true, we store the index and stop the loop using break .

If the loop completes without finding the target, position remains -1.

Input: 10 25 35 42 60

Target: 42

Output: Found at index: 3
C++ IMPLEMENTATION

Binary Search in C++

binary-search.cpp 
#include <iostream>

using namespace std;

int main()
{
    int arr[] =
        {10, 20,
         30, 40,
         50, 60,
         70};

    int n = 7;

    int target = 50;

    int low = 0;

    int high = n - 1;

    int position = -1;

    while(
        low <= high
    )
    {
        int mid =
            low + (high - low) / 2;

        if(
            arr[mid] == target
        )
        {
            position = mid;
            break;
        }

        else if(
            arr[mid] < target
        )
        {
            low = mid + 1;
        }

        else
        {
            high = mid - 1;
        }
    }

    if(
        position != -1
    )
    {
        cout <<
        "Found at index: "
        << position;
    }
    else
    {
        cout <<
        "Element not found";
    }

    return 0;
}

Most Important Formula

The middle index is calculated as:

mid = low + (high - low) / 2

If target is greater than arr[mid], move to the right:

low = mid + 1

Otherwise search the left half:

high = mid - 1
