Character Access 


string s = "HELLO";

cout << s[0];   // H
cout << s[1];   // E
cout << s[2];   // L
cout << s[3];   // L
cout << s[4];   // O

First character → s[0]
Last character → s[s.length()-1]

String Traversal Algorithm 


1. Start

2. Read the string

3. Set i = 0

4. Repeat while i < length

5. Access s[i]

6. Process the character

7. Increment i

8. Stop

C++ String Program 


#include <iostream>
#include <string>

using namespace std;

int main()
{
    string s;

    cout << "Enter string: ";

    getline(cin, s);

    cout << "\nString: "
         << s;

    cout << "\nLength: "
         << s.length();

    cout << "\nCharacters:\n";

    for(int i = 0; i < s.length(); i++)
    {
        cout << i
             << " : "
             << s[i]
             << endl;
    }

    return 0;
}
