Array Sorting

Learn how arrays are arranged in ascending or descending order using important sorting techniques required for DSA and AKTU examinations.

What is Sorting?

Sorting is one of the fundamental operations in Data Structures.

Sorting means arranging elements of a collection in a particular order.


Usually elements are arranged in:

⬆️ Ascending Order: Smallest → Largest
⬇️ Descending Order: Largest → Smallest

Important Sorting Algorithms

AKTU preparation ke liye in sorting algorithms ko conceptually samajhna important hai.

01

Bubble Sort

Adjacent elements ko compare karke incorrect order mein hone par swap karta hai.


  • Easy to understand
  • Repeated adjacent comparison
  • Simple implementation
02

Selection Sort

Har pass mein minimum element find karke usko correct position par place karta hai.


  • Minimum element select karta hai
  • Number of swaps relatively low
03

Insertion Sort

Element ko sorted portion mein appropriate position par insert karta hai.


  • Nearly sorted data ke liye useful
  • Small datasets ke liye useful
04

Merge Sort

Array ko repeatedly divide karke sorted arrays ko merge karta hai.


  • Divide and Conquer
  • O(n log n) complexity

Bubble Sort Pseudocode 

BubbleSort(A, n)

for i = 0 to n-2

    for j = 0 to n-i-2

        if A[j] > A[j+1]

            swap(A[j], A[j+1])

        end if

    end for

end for

Bubble Sort C++ Code

C++ Implementation 💻 DSA 
#include <iostream>
using namespace std;

int main() {

    int arr[] = {5, 3, 8, 1, 2};

    int n = 5;

    for(int i = 0; i < n - 1; i++) {

        for(int j = 0; j < n - i - 1; j++) {

            if(arr[j] > arr[j + 1]) {

                int temp = arr[j];

                arr[j] = arr[j + 1];

                arr[j + 1] = temp;
            }
        }
    }

    cout << "Sorted Array: ";

    for(int i = 0; i < n; i++) {

        cout << arr[i] << " ";
    }

    return 0;
}
