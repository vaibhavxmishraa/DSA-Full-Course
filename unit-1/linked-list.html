NEXT Next node address

Array vs Linked List

Feature Array Linked List
Memory Contiguous Non-contiguous
Size Usually fixed Dynamic
Random Access Fast O(1) Slow O(n)
Insertion Can require shifting Efficient with pointer access
Deletion Can require shifting Efficient with pointer access
Extra Memory Low Pointer required

Types of Linked List

➡️

Singly Linked List

Har node sirf next node ko point karta hai. 


10 → 20 → 30 → NULL
↔️

Doubly Linked List

Node ke paas previous aur next dono pointers hote hain. 


NULL ← 10 ⇄ 20 ⇄ 30 → NULL
🔄

Circular Linked List

Last node first node ko point karta hai. 


10 → 20 → 30
↑         ↓
└─────────┘
🔄

Circular Doubly Linked List

Previous aur next pointers dono circular structure maintain karte hain. 


10 ⇄ 20 ⇄ 30
↑           ↓
└───────────┘

Insertion in Linked List

1

Insertion at Beginning 


newNode->next = head;

head = newNode;

Time: O(1)

2

Insertion at End 


temp = head;

while(temp->next != NULL)
{
    temp = temp->next;
}

temp->next = newNode;

Basic implementation: O(n)

3

Insertion at Position 


newNode->next =
temp->next;

temp->next =
newNode;

Traversal required depending on position.

Deletion in Linked List

1

Delete Beginning 


temp = head;

head = head->next;

delete temp;

Time: O(1)

2

Delete End 


temp = head;

while(temp->next->next
      != NULL)
{
    temp = temp->next;
}

delete temp->next;

temp->next = NULL;

Basic implementation: O(n)

3

Delete Position 


temp->next =
temp->next->next;

Position tak traversal required.

Complete C++ Implementation 


#include <iostream>

using namespace std;

struct Node
{
    int data;
    Node* next;
};


void display(Node* head)
{
    Node* temp = head;

    while(temp != NULL)
    {
        cout << temp->data
             << " → ";

        temp = temp->next;
    }

    cout << "NULL\n";
}


void insertBeginning(
    Node*& head,
    int value)
{
    Node* newNode =
        new Node();

    newNode->data =
        value;

    newNode->next =
        head;

    head = newNode;
}


void insertEnd(
    Node*& head,
    int value)
{
    Node* newNode =
        new Node();

    newNode->data =
        value;

    newNode->next =
        NULL;

    if(head == NULL)
    {
        head = newNode;
        return;
    }

    Node* temp = head;

    while(temp->next != NULL)
    {
        temp = temp->next;
    }

    temp->next =
        newNode;
}


void deleteBeginning(
    Node*& head)
{
    if(head == NULL)
    {
        return;
    }

    Node* temp = head;

    head = head->next;

    delete temp;
}


int main()
{
    Node* head = NULL;

    insertEnd(head, 10);
    insertEnd(head, 20);
    insertEnd(head, 30);

    display(head);

    insertBeginning(head, 5);

    display(head);

    deleteBeginning(head);

    display(head);

    return 0;
}

Pointer Concept

Linked List samajhne ke liye pointer ka concept bahut important hai. 


Node* temp = head;

Iska matlab temp head node ka address hold kar raha hai.

head → first node ka address
temp → traversal ke liye temporary pointer
next → next node ka address
NULL → list ka end

Time Complexity

Operation Singly Linked List Doubly Linked List
Access by index O(n) O(n)
Search O(n) O(n)
Insert at beginning O(1) O(1)
Delete at beginning O(1) O(1)
Insert at end* O(n) O(n)
Delete at end* O(n) O(n)

*Without maintaining a suitable tail pointer.

Advantages & Disadvantages

✅ Advantages

Dynamic size
Easy insertion/deletion at known positions
No need for contiguous memory
Useful for implementing other data structures

❌ Disadvantages

No direct/random access
Extra memory for pointers
Pointer handling can be complex
Poor cache locality compared with arrays
