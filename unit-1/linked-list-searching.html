What is Searching?

Linked List mein searching ka matlab kisi particular value ko list ke andar find karna hota hai.

Agar hume 30 search karna hai, toh head se start karke har node ka data compare kiya jayega.

Core Idea

1

Start from Head

Search hamesha normally head node se start hoti hai.

2

Compare

Current node ke data ko target value ke saath compare karo.

3

Move Next

Agar value match nahi hui toh next node par move karo.

Searching Algorithm

Step 1: head se traversal start karo.
Step 2: Current node ka data target se compare karo.
Step 3: Agar equal hai → element found.
Step 4: Agar equal nahi hai → next node par jao.
Step 5: NULL tak pahunch gaye aur value nahi mili → element not found.

Basic C++ Implementation 


bool search(Node* head, int key)
{
    Node* temp = head;

    while(temp != NULL)
    {
        if(temp->data == key)
        {
            return true;
        }

        temp = temp->next;
    }

    return false;
}

Search and Return Position

Sirf found/not-found batane ke bajay hum element ki position bhi return kar sakte hain. 


int searchPosition(
    Node* head,
    int key)
{
    int position = 1;

    Node* temp = head;

    while(temp != NULL)
    {
        if(temp->data == key)
        {
            return position;
        }

        temp = temp->next;

        position++;
    }

    return -1;
}
Return -1 ka matlab hai element list mein nahi mila.

Complete C++ Program 


#include <iostream>

using namespace std;


struct Node
{
    int data;

    Node* next;
};


void display(Node* head)
{
    Node* temp = head;

    while(temp != NULL)
    {
        cout << temp->data
             << " → ";

        temp = temp->next;
    }

    cout << "NULL\n";
}


int searchPosition(
    Node* head,
    int key)
{
    int position = 1;

    Node* temp = head;

    while(temp != NULL)
    {
        if(temp->data == key)
        {
            return position;
        }

        temp = temp->next;

        position++;
    }

    return -1;
}


int main()
{
    Node* head = NULL;


    Node* a =
        new Node{10, NULL};

    Node* b =
        new Node{20, NULL};

    Node* c =
        new Node{30, NULL};

    Node* d =
        new Node{40, NULL};


    head = a;

    a->next = b;

    b->next = c;

    c->next = d;


    cout
    << "Linked List:\n";

    display(head);


    int key = 30;


    int position =
        searchPosition(head, key);


    if(position != -1)
    {
        cout
        << "Element found at position "
        << position;
    }
    else
    {
        cout
        << "Element not found";
    }


    return 0;
}

Time & Space Complexity

Case Time Complexity Explanation
Best Case O(1) Element first node par mil gaya.
Average Case O(n) Multiple nodes check karne pad sakte hain.
Worst Case O(n) Last node ya NULL tak traversal.
Space O(1) Only temporary pointer use hota hai.

Why Searching is O(n)?

Singly Linked List mein direct indexing available nahi hoti. Aap list[5] karke fifth node directly access nahi kar sakte.

HEAD
→
Node 1
→
Node 2
→
...
→
Node n

Isliye target tak pahunchne ke liye sequential traversal karna padta hai.

Array vs Linked List Searching

Feature Array Linked List
Sequential Search O(n) O(n)

Memory Contiguous Dynamic Nodes
Pointer Required No Yes
