Three Main Insertion Cases

1

Insertion at Beginning

New node ko head se pehle add karna. 


newNode → oldHead

head = newNode;
2

Insertion at End

New node ko list ke last mein add karna. 


last → newNode → NULL
3

Insertion at Position

Kisi particular position par new node insert karna. 


A → B → C

A → B → NEW → C

Beginning Insertion Logic

Step 1: New node create karo.
Step 2: New node ka next current head ko point karega.
Step 3: Head ko new node bana do. 

Node* newNode = new Node();

newNode->data = 5;

newNode->next = head;

head = newNode;

End Insertion Logic

Step 1: New node create karo.
Step 2: New node ka next NULL rakho.
Step 3: Head se traversal start karo.
Step 4: Last node tak jao.
Step 5: Last node ka next new node ko point karao. 

Node* newNode = new Node();

newNode->data = 40;

newNode->next = NULL;

Node* temp = head;

while(temp->next != NULL)
{
    temp = temp->next;
}

temp->next = newNode;

Pointer Rearrangement

Sabse important concept: insertion ke time pointers ko correct order mein change karna.

→

Pehle new node ka next 30 ko point karwao: 


newNode->next = temp->next;

Ab 20 ka next new node ko point karwao: 


temp->next = newNode;

⚠️ Important: Pehle newNode->next set karna safer hai. Agar original next ko lose kar diya, to remaining list tak pahunchna possible nahi rahega.

C++: Insert at Position 


void insertAtPosition(
    Node*& head,
    int value,
    int position)
{
    Node* newNode =
        new Node();

    newNode->data =
        value;

    if(position == 1)
    {
        newNode->next =
            head;

        head = newNode;

        return;
    }

    Node* temp = head;

    for(int i = 1;
        i < position - 1 &&
        temp != NULL;
        i++)
    {
        temp =
            temp->next;
    }

    if(temp == NULL)
    {
        cout << "Invalid Position";
        delete newNode;
        return;
    }

    newNode->next =
        temp->next;

    temp->next =
        newNode;
}

Complete C++ Program 


#include <iostream>

using namespace std;


struct Node
{
    int data;

    Node* next;
};


void display(Node* head)
{
    Node* temp = head;

    while(temp != NULL)
    {
        cout << temp->data
             << " → ";

        temp = temp->next;
    }

    cout << "NULL\n";
}


void insertBeginning(
    Node*& head,
    int value)
{
    Node* newNode =
        new Node();

    newNode->data =
        value;

    newNode->next =
        head;

    head =
        newNode;
}


void insertEnd(
    Node*& head,
    int value)
{
    Node* newNode =
        new Node();

    newNode->data =
        value;

    newNode->next =
        NULL;

    if(head == NULL)
    {
        head =
            newNode;

        return;
    }

    Node* temp =
        head;

    while(
        temp->next != NULL
    )
    {
        temp =
            temp->next;
    }

    temp->next =
        newNode;
}

int main()
{
    Node* head =
        NULL;


    insertEnd(

Time Complexity

Insertion Time Complexity Reason
Beginning O(1) No traversal required
End O(n) Last node find karna padta hai
Specific Position O(n) Position tak traversal

Important Edge Cases

List Empty


head == NULL

Empty list mein first node directly head ban sakta hai.

Position = 1


newNode->next = head;
head = newNode;

Beginning insertion jaisa behave karega.

Invalid Position

Agar position list ki valid range se bahar hai, to insertion perform nahi karna chahiye.

Memory

Dynamic node create karne ke liye new use hota hai.

⚡ Quick Revision

Beginning insertion → O(1)
End insertion without tail → O(n)
Position insertion → generally O(n)
New node → new Node()
Beginning → newNode → old head
Position → newNode.next = temp.next
Then → temp.next = newNode
Always be careful not to lose the original next pointer.
