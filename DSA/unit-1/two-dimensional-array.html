2D Array
Row: Horizontal collection of elements.
Column: Vertical collection of elements.
Index: 2D array generally uses [row][column].

2D Array Declaration 

int arr[3][4];
3 = number of rows
4 = number of columns
Total elements = 3 × 4 = 12

Initialization of 2D Array 

int arr[2][3] = {

    {10, 20, 30},

    {40, 50, 60}

Accessing Elements

Kisi particular element ko access karne ke liye: 

arr[row][column]

Example: 

int arr[2][3] = {

    {10, 20, 30},

    {40, 50, 60}

};

cout << arr[1][2];
Output: 60
Because: arr[1][2] = 60

2D Array C++ Program 

#include <iostream>
using namespace std;

int main() {

    int arr[3][3] = {

        {1, 2, 3},

        {4, 5, 6},

        {7, 8, 9}

    };


    cout << "2D Array:" << endl;


    for(int i = 0; i < 3; i++) {

        for(int j = 0; j < 3; j++) {

            cout << arr[i][j] << " ";

        }

        cout << endl;

    }


    return 0;
}

Advantages & Limitations

✅ Advantages

Data ko table form mein organize karna easy.
Matrix problems ke liye useful.
Direct indexing possible.
Images aur grids represent kar sakte hain.

⚠️ Limitations

Traditional arrays ka size fixed hota hai.
Large unused matrices memory waste kar sakti hain.
Dynamic structures ki comparison mein less flexible.
