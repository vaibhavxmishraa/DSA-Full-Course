What is Array Insertion?

THREE CASES

Types of Insertion

⬅️

Beginning

Insert the new element at index 0. Almost every existing element needs to shift right.

position = 0
🎯

Middle / Any Position

Elements from the insertion position onward are shifted one position right.

0 ≤ position ≤ n
➡️

End

If free capacity exists, simply place the new element at the end.

position = n

For insertion at position pos , shift elements from the end toward pos .

Step 1: Check whether array has free space.

Step 2: Start from the last element.

Step 3: Shift each element one position right.

Step 4: Put the new element at position pos.

Step 5: Increase logical size by 1.

C++ IMPLEMENTATION

Insert Element at Given Position

insertion.cpp 
#include <iostream>

using namespace std;

int main()
{
    int arr[10] =
        {10, 20, 30, 40};

    int n = 4;

    int pos = 2;

    int value = 25;

    for(
        int i = n;
        i > pos;
        i--
    )
    {
        arr[i] = arr[i - 1];
    }

    arr[pos] = value;

    n++;

    for(
        int i = 0;
        i < n;
        i++
    )
    {
        cout << arr[i] << " ";
    }

    return 0;
}

Important Lines

arr[i] = arr[i - 1] shifts the existing element one position toward the right.

The loop starts from i = n because we must first move the last element.

Shifting is done from right → left in the loop so that no existing value gets overwritten before being moved.

After: 10 20 25 30 40

COMPLEXITY

Time Complexity of Insertion

O(1) Best Case — Insert at End
O(n) Worst Case — Insert at Beginning
O(n) Average Case
Position Shifting Time Reason
Beginning Almost n elements O(n) All elements move right
Middle Some elements O(n) Elements after position shift
End No shifting O(1) Direct placement

Important AKTU point: Insertion in an array can be expensive because elements may need to be shifted.

Unlike accessing arr[i] which is O(1), insertion at an arbitrary position can take O(n).
