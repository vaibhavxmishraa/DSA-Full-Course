Sparse Matrix

Learn how matrices containing mostly zero values can be represented efficiently using sparse matrix techniques.

What is a Sparse Matrix?

A matrix in which most of the elements are zero is called a Sparse Matrix.

Suppose ek matrix mein 100 elements hain, lekin sirf 10 elements non-zero hain. Baaki 90 elements zero hain.


Sparse Matrix: Mostly zero elements.
Non-Zero Elements: Actual useful values.
Main Goal: Memory ko efficiently use karna.

Sparse Matrix Algorithm 


1. Start

2. Read matrix

3. Traverse every element

4. If element != 0

       Store row index

       Store column index

       Store value

5. Continue until matrix ends

6. Stop

Pseudocode for Conversion 


for i = 0 to rows - 1

    for j = 0 to columns - 1

        if A[i][j] != 0

            store i

            store j

            store A[i][j]

        end if

    end for

end for

C++ Implementation 


#include <iostream>
using namespace std;

int main()
{
    int arr[3][4] = {

        {5, 0, 0, 8},

        {0, 4, 0, 0},

        {0, 0, 7, 0}

    };

    int rows = 3;
    int cols = 4;

    cout << "Row Column Value\n";

    for(int i = 0; i < rows; i++)
    {
        for(int j = 0; j < cols; j++)
        {
            if(arr[i][j] != 0)
            {
                cout
                << i
                << "    "
                << j
                << "    "
                << arr[i][j]
                << endl;
            }
        }
    }

    return 0;
}

Why use Sparse Matrix?

✅ Advantages

Memory wastage reduce hoti hai.
Large matrices ke liye useful.
Sirf useful/non-zero values store hoti hain.
Storage efficient hoti hai.

⚠️ Limitations

Representation thoda complex hota hai.
Direct access normal matrix jitna simple nahi hota.
Agar zeros kam hain to sparse representation ka benefit kam ho sakta hai.

Time & Space Complexity

Operation Complexity
Traverse Matrix O(rows × columns)
Conversion to Sparse O(rows × columns)
Sparse Storage O(non-zero elements)
